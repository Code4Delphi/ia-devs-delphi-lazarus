# IA para Desenvolvedores Delphi e Lazarus na Prática

Página de vendas do curso, publicada com Vite no GitHub Pages.

## Desenvolvimento local

```bash
npm ci
npm run dev
```

## Publicação

Cada push para a branch `master` gera o site e publica automaticamente em:

https://code4delphi.github.io/ia-devs-delphi-lazarus/

Na primeira publicação, abra `Settings > Pages` no repositório e selecione
`GitHub Actions` em `Build and deployment > Source`.
